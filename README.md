# OmniForge

OmniForge is a provider-agnostic, self-optimizing AI software factory designed to execute authoritative software roadmaps continuously across a heterogeneous fleet of AI models and providers.

The project separates model identity, provider identity, and inference route; dynamically routes planning, coding, repair, review, and arbitration work; preserves deterministic validation and Git/authority safety; and learns from production outcomes without allowing model reputation to bypass required integrity gates.

## Current status

OmniForge is in initial bootstrap under the authoritative roadmap at `docs/OMNIFORGE_FULL_ROADMAP_v1.0.md`.
